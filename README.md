# Матшаг

Математика для урока. Одна тема — на доске, на бумаге и дома.

Интерактивные материалы для учителей математики 5–9 классов: **5–6 класс — Виленкин, 7–9 класс — алгебра
Макарычева и геометрия Мерзляка.**

У математика нет компьютерного класса: в классе один экран и тетради. Поэтому каждый материал — одна тема
в трёх режимах на одном генераторе заданий:

| Режим | Где | Что делает |
|---|---|---|
| 🖥 На доске | урок, проектор | пошаговый живой чертёж: учитель ведёт, класс отвечает |
| 🖨 Раздатка | урок, бумага | у каждого свой вариант, ключ учителю — по номеру варианта |
| 🏠 Дома | телефон или компьютер ученика | тренажёр по ссылке из чата класса, с разбором каждой ошибки |

Каждый материал — один HTML-файл: открывается в браузере и работает без интернета, в том числе с флешки.

**Статус:** сайт опубликован на [matshag.ru](https://matshag.ru), идёт наполнение — этап 5 (`docs/ROADMAP.md`).
Новые материалы собирает конструктор — отдельный репозиторий
[`matematika-konstruktor`](https://github.com/kuzmin-lemmi/matematika-konstruktor), порядок работы — `AGENTS.md`, раздел 4.
Соседний проект автора — [«Инфошаг»](https://github.com/kuzmin-lemmi/personal_ebsite), игры по информатике; каркас сайта взят оттуда.

## Запуск на своём компьютере

Нужен Node.js 22 (от 22.13) или 24 и новее, npm от 9.6.5. Версия для разработки и CI указана
в `.nvmrc`. Для nvm-windows используй `nvm install 22` и `nvm use 22`;
для nvm в Linux/macOS — `nvm install` и `nvm use`.

При первом запуске из новой папки:

```bash
git clone https://github.com/kuzmin-lemmi/matematika.git
cd matematika
```

```bash
npm ci           # установить точные версии из package-lock.json
npm run dev      # http://localhost:4321/
npm run validate # TypeScript, автотесты и сборка
npm run preview  # просмотр собранного сайта
```

Сервер останавливается сочетанием `Ctrl+C`.
Секреты, `.env` и подключение внешних сервисов для локальной разработки не нужны.
В Windows, если PowerShell запрещает запуск `npm.ps1`, используй `npm.cmd` вместо `npm`.

Отдельные проверки: `npm run check`, `npm test`, `npm run build`.
GitHub Actions выполняет `npm run validate` при push в `main` и в pull request; публикация остаётся ручной.
`@astrojs/check`, TypeScript и `@types/node` нужны для проверки типов, `jsdom` — для автотестов HTML-материалов.

## Тесты материалов

Основа готова в `tests/helpers.mjs`: загрузчик выполняет встроенные скрипты, передаёт параметры адреса,
собирает ошибки и не загружает внешние ресурсы. У каждого материала свой тест `tests/<slug>.test.mjs`
с независимым решением заданий; отдельно проверяются план уроков, поиск и шаблон. Начало такого теста:

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { loadMaterial } from './helpers.mjs';

test('доска запускается без ошибок', t => {
  const material = loadMaterial('slozhenie-drobei', { query: '?mode=board' });
  t.after(material.close);
  assert.ok(material.window.APP);
  assert.deepEqual(material.errors, []);
});
```

`window.APP` — интерфейс материала для тестов. Всегда закрывай окно через `t.after(material.close)`,
чтобы остановить таймеры. Требования к проверке генератора, ключей и шагов доски — в `AGENTS.md` и `docs/TECH.md`.

## Структура

```
AGENTS.md, CLAUDE.md      правила для ИИ-агентов
docs/                    стратегия, план, форматы, банк идей, техника, домашние задания, сайт
src/config.ts            название, классы, предметы, режимы
src/content.config.ts    поля карточки материала
src/content/items/       карточки материалов (по одной на файл)
src/data/                рабочие программы: уроки по номерам и четвертям
src/pages/               главная, каталог, план класса, поиск, страница материала, запуск
public/materials/        сами материалы — самодостаточные HTML-файлы
public/posts/            картинки-превью и ролики
scripts/                 подготовка превью
```
