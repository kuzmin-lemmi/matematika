**На доске.** Десять шагов, у каждого — вопрос классу, потом показ. На экране только короткий вопрос, ответ и полоски,
внизу растёт запись для тетради; что сказать словами — в подсказке учителю. Сначала ловушка: «2/3 + 3/4 = 5/7?» —
полоски показывают, что 5/7 меньше одного из слагаемых. Потом доли дробятся до общего знаменателя на глазах
класса, считаются дополнительные множители, складываются доли, выделяется целая часть. Отдельные шаги —
«произведение знаменателей или НОК» и вычитание. Кнопка «Другие числа» повторяет показ с новыми дробями.

**Раздатка.** Шесть заданий в варианте: знаменатель делится на другой, взаимно простые знаменатели,
знаменатели с общим делителем, ответ с сокращением, с выделением целой части и вычитание. Верные ответы
складываются в слово, ответы-ловушки на типичных ошибках дают другие буквы. Номер варианта восстанавливает
и задания, и ключ. Можно печатать с сеткой для решения или по два варианта на листе.

**Дома.** Тренажёр по шагам: общий знаменатель → дополнительные множители → числитель → сокращение → целая часть.
Три уровня, вычитание по желанию. Каждая ошибка объясняется с вычислением, типичные называются прямо:
«сложил знаменатели», «домножил только знаменатели». После ошибки — такое же задание с другими числами,
в итогах — «Над чем поработать». Верные шаги засчитываются сами, на телефоне удобно. Кнопка «🔗 Ссылка для дома»
копирует ссылку для чата класса: ученик попадает сразу в тренажёр, без сайта, доски и раздатки.
