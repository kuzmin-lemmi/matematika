**На доске.** Двенадцать шагов «вопрос → показ» с чертежами в общем оформлении «Матшага».
Четыре одинаковых прямоугольных треугольника перемещаются внутри неизменной квадратной рамки.
Свободное место превращается из квадрата на гипотенузе в два квадрата на катетах: так видно
доказательство теоремы. Катеты можно менять, движение повторять, чертёж увеличивать.
Отдельный эксперимент с углами 60°, 90°, 120° показывает необходимость прямого угла.
Затем — нахождение гипотенузы, катета и разбор ошибки «c = a + b».

**Раздатка.** Семь задач с кодовым словом: гипотенуза, катет, диагональ прямоугольника,
лестница у стены, сокращение пути и условие применения теоремы. Печать A4 с клеткой,
без клетки и по два варианта на странице. Дополнительно — бланк ответов как в ОГЭ
с отдельными числовыми заданиями. Задания и ключ обоих видов листа восстанавливаются по номеру.

**Дома.** Четыре раздела: гипотенуза; катет; проверка рассуждений; применение.
Есть задачи с повёрнутыми чертежами, поиск первого неверного шага и точные ответы с корнем.
Подсказки, объяснение каждой ошибки и справка с теорией. Для ученика — отдельная ссылка на тренировку.
