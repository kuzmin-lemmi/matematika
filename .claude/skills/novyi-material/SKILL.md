# Новый материал — через конструктор

Материалы собираются конструктором — репозиторий `kuzmin-lemmi/matematika-konstruktor` (общее ядро + тема → один HTML
в `public/materials/<slug>.html` этого сайта). Папка конструктора на каждом компьютере своя (на работе
`D:\Конструктор математика`, дома `F:\конструктор математика`) — не угадывай, спроси автора, если её нет в сессии.

1. Прочитай полный навык конструктора `.claude/skills/novyi-material/SKILL.md` и его `ИНСТРУКЦИЯ.md`.
   Если папка недоступна — попроси автора открыть к ней доступ.
2. Работай с темой в конструкторе. Собирая из worktree сайта, передавай `--site <папка worktree>`:
   `npm run build -- <slug> --site <папка>`.
3. Файлы с комментарием «Собрано конструктором» руками не правь — правь тему или ядро и пересобирай.
4. Сайтовая часть (независимый тест темы, карточка) — по навыку конструктора, раздел 5. Проверка — `npm run check -- <slug>`,
   показ — `npm run show -- <slug>`, публикация — `npm run publish -- <slug> --approved` в папке конструктора и только
   после явного одобрения автора в чате.
