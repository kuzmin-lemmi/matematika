# Новый материал — через конструктор

Материалы собираются конструктором в папке `D:\Конструктор математика` (общее ядро + тема → один HTML
в `public/materials/<slug>.html` этого сайта).

1. Прочитай полный навык: `D:\Конструктор математика\.claude\skills\novyi-material\SKILL.md`
   и `D:\Конструктор математика\ИНСТРУКЦИЯ.md`. Если папка недоступна — попроси автора открыть к ней доступ.
2. Работай с темой в конструкторе. Собирая из worktree сайта, передавай `--site <папка worktree>`:
   `npm run build -- <slug> --site <папка>`.
3. Файлы с комментарием «Собрано конструктором» руками не правь — правь тему или ядро и пересобирай.
4. Сайтовая часть (независимый тест темы, постер, карточка, `npm run validate`, публикация) — по навыку конструктора,
   раздел 5, и `AGENTS.md` этого репозитория.
