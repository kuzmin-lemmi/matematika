# Материалы: пилот и банк идей

Что делать по каждому учебнику и какие ошибки учеников ловить. Порядок тем и их распределение по классам
**сверять с изданием учебника у автора** — издания разных лет отличаются. Номера параграфов здесь не указываем.

Для каждой темы: 🖥 что показать на доске, 🖨 что напечатать, 🏠 что тренировать дома, ⚠️ типичные ошибки —
из них строятся ловушки и объяснения.

## Пилот: три материала

Цель пилота — проверить формат «одна тема — три режима» на трёх разных учебниках, показать коллегам
и по отзывам решить, двигаться ли дальше. Карточки уже есть в `src/content/items/` с `access: soon`.

### 1. Геометрия 7 — «Углы при параллельных прямых» (`ugly-pri-parallelnyh-pryamyh`)

- 🖥 Две прямые a и b, секущая c. Учитель поворачивает секущую и сдвигает прямые — восемь углов пересчитываются.
  Шаги: назвать пары (накрест лежащие, соответственные, односторонние) → предсказать, какие равны → показать →
  «а если прямые не параллельны?» — равенства пропадают → обратная теорема (признак параллельности).
- 🖨 Задачи на готовых чертежах с генерируемыми числами: найти угол, доказать параллельность, угол между
  биссектрисами. Таблица ответов внизу, ключ по номеру варианта.
- 🏠 Найти угол по чертежу; назвать вид пары углов; выбрать обоснование («как накрест лежащие при a ∥ b»).
- ⚠️ Путают накрест лежащие и соответственные; односторонние считают равными (а их сумма 180°);
  применяют свойство, не проверив параллельность; путают теорему и признак.

### 2. Алгебра 7 — «Формулы сокращённого умножения» (`formuly-sokrashchennogo-umnozheniya`)

- 🖥 Квадрат со стороной a + b разрезан на a², ab, ab, b²; ползунки a и b. Шаг-ловушка: где «пропадают»
  два прямоугольника ab в записи (a + b)² = a² + b². То же для (a − b)² и для a² − b² (перекладывание прямоугольника).
- 🖨 Варианты: раскрыть скобки, свернуть в квадрат, вычислить удобным способом (51², 49 · 51), разложить на множители.
- 🏠 Заполнение клеток: «(3x − 2)² = □x² − □x + □»; выбор верного разложения; вычисление удобным способом.
- ⚠️ (a + b)² = a² + b²; (a − b)² = a² − b²; знак удвоенного произведения; (3x)² = 3x²;
  удвоенное произведение без двойки; путают (a − b)² и a² − b².

### 3. Математика 6 — «Сложение дробей с разными знаменателями» (`slozhenie-drobei`)

- 🖥 Две полоски-дроби; доли дробятся до общего знаменателя на глазах класса; затем то же числами.
  Шаг-ловушка: «сложили числители и знаменатели» — полоски показывают, что 2/3 + 3/4 > 1, а 5/7 < 1.
- 🖨 Варианты с кодовым словом; у каждого свой номер; ключ по номеру.
- 🏠 Пошаговый ввод: общий знаменатель → дополнительные множители → сумма → сокращение → выделение целой части.
- ⚠️ Складывают числители и знаменатели; домножают только знаменатель; берут произведение знаменателей
  вместо НОК (не ошибка, но громоздко — подсказать); не сокращают ответ; ошибаются в выделении целой части.

**Порядок работы над пилотом:** сначала шаблон материала вместе с первым пилотом (`docs/ROADMAP.md`, этап 1),
потом остальные два на этом шаблоне.

## Геометрия 7–8 (Мерзляк)

**Про преобразования.** По памяти, отдельная глава о движениях (осевая и центральная симметрия, поворот,
параллельный перенос, гомотетия) у Мерзляка — в **9 классе**; сверить по изданию. В 7–8 классах
преобразования работают как инструмент: наложение — в признаках равенства треугольников, симметрия —
в свойствах равнобедренного треугольника, ромба, параллелограмма, растяжение — в подобии.

| Смежные и вертикальные углы | вращаем прямую — углы пересчитываются | задачи на готовых чертежах | найти угол | путают смежные и вертикальные |

## Форматы, общие для всех классов

- **Устный счёт на проекторе** — отдельный материал на весь год для 5–6 классов.
- **Задачи на готовых чертежах** (геометрия) — классический формат: чертёж с данными, ответ — число.
- **«Найди ошибку в решении»** — готовое решение с ошибкой на одном из шагов.
- **«Близнец»** — короткая проверка на бумаге по теме домашней работы (`docs/HOMEWORK.md`).
- **Наборы на четверть** — раздатки и ключи по тематическому плану (позже, возможно платно).
