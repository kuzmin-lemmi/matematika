# Устройство сайта

Что уже есть, какие адреса постоянны и что закладываем под будущий сервер.

## Сейчас

- Astro 7, статическая сборка, GitHub Pages (пока не включён: сборка вручную, см. `docs/ROADMAP.md`, этап 4).
- Коллекция `items` (`src/content/items/*.md`) — все продукты: материалы к урокам, позже курсы и программы.
- У материала: предмет `subject` (math, algebra, geometry), классы `grades`, режимы `parts` (board, print, home), доступ `access`.
- Страницы:
  - главная — три режима, блок «Новое» (последний опубликованный материал по `added`), плитки классов, полки по классам;
  - каталог — фильтры по предмету, классу, режиму и поиск; состояние фильтров — в адресе;
  - класс — материалы по предметам (в 7–8 — отдельно алгебра и геометрия);
  - страница материала — кнопки режимов, «Скачать», «Скопировать ссылку для учеников»;
  - запуск материала — на весь экран.
- Материалы с `access: soon` — карточка без кнопок, страница с `noindex`, вне sitemap; страница запуска не создаётся.

## Адреса — правило на всё время жизни сайта

Всё, что уходит наружу (раздатки, посты, чат класса, письма), указывает на **страницы**, а не на файлы:

| Адрес | Что это |
|---|---|
| `/` | главная |
| `/catalog/?subject=geometry&grade=7&part=print` | каталог с фильтрами |
| `/klass/<класс>/` | материалы класса |
| `/item/<slug>/` | страница материала: описание, превью, кнопки режимов, «Скачать» |
| `/zapusk/<slug>/` | материал на весь экран (обёртка над `materials/<slug>.html`) |
| `/zapusk/<slug>/?mode=board` | сразу доска |
| `/zapusk/<slug>/?mode=print` | сразу раздатка |
| `/zapusk/<slug>/?mode=home` | **ссылка для учеников** — сразу тренажёр |

Почему: когда появится сервер, `/zapusk/<slug>/` сможет проверить доступ, а файл переедет за авторизацию —
и ни одна ссылка не сломается. Slug после публикации **не меняется никогда**.
Для домашних заданий с сервером зарезервирован адрес `/dz/…` (`docs/HOMEWORK.md`).

Пока сайт живёт на `kuzmin-lemmi.github.io/matematika/`, адреса начинаются с `/matematika/`. После переезда на свой
домен они сменятся — поэтому **до покупки домена адреса наружу не раздаём** (раздатки с адресом сайта не печатаем).

## Модель доступа (закладываем сейчас, включаем вместе с сервером)

**У продукта** — поле `access`: `free` | `paid` | `external` | `soon`. Сейчас у готовых — `free`.

**Внутри материала** — режимы с уровнем доступа. Конфиг в начале скрипта:

```js
const ACCESS = { board: 'free', print: 'free', home: 'free' };   // позже, например: журнал ДЗ — по подписке
```

Материал узнаёт о доступе через `window.SITE_ACCESS` (выставит страница-обёртка `/zapusk/<slug>/`)
или считает всё доступным, если его открыли отдельно. Закрытый режим показывает объяснение, а не исчезает молча.
Сами материалы остаются бесплатными и скачиваемыми; платным может стать только то, что живёт на сервере
(`docs/STRATEGY.md`, «Деньги»).

## Чего не делаем без автора

Сервер, база данных, вход, платежи, аналитика, сторонние скрипты, смена хостинга или домена,
удаление страниц и смена slug. Подробно — `AGENTS.md`, раздел 9.
