# План уроков по четвертям

Страницы `/klass/5/`–`/klass/9/` показывают уроки слева и компактные кнопки материалов справа.
Ссылки классов в шапке и на главной уже ведут на эти постоянные адреса.

## Темы и четверти

`src/data/lesson-plans.json` содержит восемь планов: математика 5–6, алгебра и геометрия 7–9.
Всего 850 уроков. Названия и последовательность взяты из разделов «Поурочное планирование» рабочих
программ гимназии № 87 Саратова, утверждённых 29.08.2025:

- [Математика 5–6](https://gim87-sar.gosuslugi.ru/netcat_files/30/69/4._matematika_5_6_pod.pdf).
- [Алгебра 7–9](https://gim87-sar.gosuslugi.ru/netcat_files/30/69/5._algebra_7_9_podp.pdf).
- [Геометрия 7–9](https://gim87-sar.gosuslugi.ru/netcat_files/30/69/6._geometriya_7_9_podp.pdf).

Повторяющиеся названия сохранены: это отдельные уроки на одну тему. Исправлены переносы строк из PDF
и символы квадратного корня, неверно извлечённые из текста. Не переносились даты, внешние учебные ресурсы
и графы контрольных работ; сами уроки контрольных работ оставлены.

Границы четвертей **не взяты из программы**: это ориентировочная схема сайта 8 + 8 + 10 + 8 недель
при 5 часах математики, 3 часах алгебры и 2 часах геометрии. `quarterEnds` — последние номера уроков
за год в каждой четверти. Их можно менять без изменения привязок материалов. На странице об этом
есть примечание и ссылки на источники. План не заявлен как КТП конкретного учителя или конкретного
издания Макарычева: учебные линии гимназии и сайта в 8–9 классах могут отличаться.

Внутри каждой четверти номера начинаются с 1. Фильтр «Только с материалами» скрывает пустые уроки,
но не перенумеровывает оставшиеся. Предмет, четверть и фильтр сохраняются в параметрах URL
`subject`, `quarter`, `ready=1`. Без JavaScript видны все уроки и рабочие ссылки материалов.

## Добавление материалов к уроку

В карточке `src/content/items/<slug>.md` добавить поле:

```yaml
planLessons:
  - { grade: 8, lessons: [20, 26, 27] }
```

Это **номера уроков за год** (позиции с 1 в массиве `lessons`), а не номера внутри четверти.
Предмет берётся из `subject` карточки. К одному уроку можно привязать любое число карточек,
к одному материалу — любое число уроков. Ограничения на количество кнопок нет: полка прокручивается
горизонтально, при переполнении появляются стрелки. Для нескольких материалов в кнопках видны
их названия; доступное имя ссылки всегда содержит название материала.

Кнопки формируются из реально доступных `parts`: `board` → «Практика», `home` → «Тренажёр»,
`print` → «Печать»; виды листов `sheets` имеют свои короткие названия. Открытие — через существующий
`/zapusk/<slug>/?mode=…`. Материалы `soon` не считаются готовыми и не получают ссылок запуска.
Готовые материалы без привязки остаются в разделе «Ещё материалы», поэтому новые публикации не пропадают.

Добавление выполняет автор через карточки репозитория. Демонстрационный «+» из макета на публичную
страницу не перенесён: сайт статический, редактор с авторизацией не создавался.

Проверка: `npm run validate`. Тест `tests/lesson-plan.test.mjs` проверяет полноту планов,
границы четвертей, привязки карточек и переключение состояния страницы.
