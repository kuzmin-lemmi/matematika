# Три режима материала

Стандарт для каждого материала в `public/materials/`. Обязательный минимум — в `AGENTS.md`, раздел 5;
здесь — подробности и причины. Техника (генератор, дроби, SVG, печать) — `docs/TECH.md`.

Один материал = одна тема урока = один HTML-файл. Внутри — до трёх режимов на одном генераторе заданий.
Не каждой теме нужны все три: устному счёту не нужна раздатка, карточкам для печати — доска. В карточке
материала поле `parts` перечисляет только то, что есть.

## Общий каркас

- **Стартовый экран** (если адрес без `?mode`): название темы, класс и учебник, три большие кнопки режимов —
  «🖥 На доске», «🖨 Раздатка», «🏠 Тренировка» — и короткая строка о каждом.
- **Адрес:** `?mode=board | print | home` открывает режим сразу (так ведут кнопки на сайте и ссылка для учеников);
  `?preview=1` — превью на сайте и снимок `npm run posters`: без звука, без фокуса, доска сама показывает движение.
- **`CONFIG`** в начале скрипта — все параметры, которые учитель может захотеть поменять.
- **Клавиатура:** Esc — назад в меню (на доске — выход из полноэкранного режима), F — во весь экран.
- **Тема:** светлая и тёмная по системе; на доске — кнопка переключения (проектор в светлом классе читается лучше со светлой темой).
- **Версия генератора** — константа `GEN_VERSION`; входит в номер варианта (см. «Раздатка»).

## 🖥 На доске

**Зачем:** у учителя один экран и 30 учеников. Материал на доске — не «поиграть ползунками», а **сценарий урока**,
который учитель ведёт по шагам.

**Сценарий из шагов**
- Каждый шаг: **вопрос классу → пауза → показ.** Догадка до показа запоминается лучше, чем готовый ответ.
  Пример: «Что станет с углом 2, если повернуть секущую?» — класс отвечает — учитель жмёт «Показать».
- Кнопки «Далее», «Назад», «Заново», «Показать ответ», «Во весь экран», «Другие числа» (тот же сценарий с новыми данными).
- Пульт для презентаций шлёт `PageDown`/`PageUp` — это «Далее»/«Назад». Ещё `→`/`←` и `Пробел`.
- Учитель задаёт темп: никаких самозапускающихся таймеров в показе.
- Номер шага и их число видны («Шаг 3 из 7»), чтобы учитель понимал, сколько осталось.
- **На экране — только то, что видит класс:** вопрос одной фразой, короткий ответ, крупный чертёж. Объяснение словами —
  в подсказке учителю (кнопка «💬 Учителю», по умолчанию скрыта: её видно и на проекторе).
- Внизу — **запись в тетради**: строки, которые ученики переписывают, растут по шагам.
- Внизу экрана только «Назад» и «Показать ответ / Далее»; остальные кнопки — мелко в верхней строке. Проверять на проекторе 1024×768.

**Живой чертёж**
- Точки и прямые можно тянуть мышью и пальцем (интерактивная доска), но значения «прилипают» к удобным:
  углы — к 5°, длины — к целым. На доске должны получаться школьные числа, а не 37,4°.
- Подписи вершин и углов крупно, отнесены от линий; толщина линий от 4px.
- Смысл передаётся не только цветом: проектор искажает цвета, а у части учеников нарушено цветовосприятие.
  Пары углов — цвет **и** форма дужки (одна, две черты), равные отрезки — штрихи.
- Отдельный шаг «а если условие нарушить» (прямые не параллельны, треугольник не прямоугольный) —
  чтобы было видно, зачем в теореме каждое условие.

**Игровые форматы для доски**
- **Устный счёт:** цепочки примеров с таймером, ответы открываются в конце. Новые каждый урок (5–6 класс — классика начала урока).
- **Математический диктант:** задания по одному с таймером, ученики пишут ответы в тетрадь, в конце — все ответы для самопроверки.
- **Команды по рядам:** счёт команд на экране, вопрос — ряд отвечает — учитель отмечает.
- **Дуэль у интерактивной доски:** экран пополам, двое отвечают одновременно, у каждого свои задания.
- **«Верно — неверно» с сигнальными карточками:** на экране утверждение, ученики поднимают карточки
  (бумага, ничего больше не нужно), учитель видит класс сразу.

## 🖨 Раздатка

**Зачем:** без компьютерного класса бумага — главный способ дать каждому своё задание. Сервер не нужен.

**Номер варианта = ключ**
- Номер варианта (например, «Вариант 2-4817») — это зерно генератора: по нему заново собираются и задания, и ответы.
  Ничего не хранится, у каждого ученика свой вариант, учитель восстанавливает ключ по номеру в любой момент.
- Первая часть номера — `GEN_VERSION`: если генератор поменяется, старые листы со старыми номерами
  должны по-прежнему давать свои ответы. Старые версии генератора не удаляем, пока на них есть листы.
- Один и тот же номер всегда даёт один и тот же вариант — это проверяет автотест.

**Настройки перед печатью:** типы заданий, число заданий, сложность, число вариантов (по числу учеников),
«с местом для решения» или «только ответы», два варианта на листе A4 (экономия бумаги).

**Лист ученика**
- Шапка: «Фамилия, имя», «Класс», «Дата», «Вариант №».
- Задания с местом для решения — сетка в клетку 5 мм, как в тетради.
- **Таблица ответов внизу листа:** учитель сверяет ответы с ключом за секунды, не читая решения.

**Ключ учителя:** одна страница на все варианты — строки «вариант — ответы»; по желанию — полные решения.

**Самопроверка без учителя**
- **Кодовое слово:** каждому ответу соответствует буква, верные ответы складываются в слово.
  Неверные ответы-ловушки дают другие буквы — ученик видит, что слово не сложилось, и ищет ошибку.
- **Рисунок по координатам:** верно найденные точки складываются в картинку.

**Другие форматы печати**
- Разрезные карточки: домино, пары «задача — ответ», лото — для работы в группах.
- «Найди ошибку в решении»: готовое решение с ошибкой, найти шаг и исправить.
- Задачи на готовых чертежах (геометрия): чертёж с данными, ответ — число.
- **«Близнец» для проверки домашней работы:** 5–7 минут в начале урока, те же типы задач, что в ДЗ, другие числа
  (`docs/HOMEWORK.md`).

**Печать:** A4, чёрным по белому, шрифт от 12 pt, задание не разрывается между страницами, интерфейс скрыт.
Проверять в предпросмотре печати Chrome и Яндекс Браузера.

## 🏠 Дома (тренажёр)

**Зачем:** дома у ученика есть устройство. Тренажёр — не оценка, а тренировка с разбором: «добей до понимания».

- **Ссылка для учеников** — `/zapusk/<slug>/?mode=home&student=1`: кнопка «🔗 Ссылка для дома» есть в каждой карточке
  (каталог, список класса, страница материала), учитель отправляет ссылку в чат класса. С `student=1` материал открывает
  **только тренажёр**: нет меню, Esc не выводит на стартовый экран, доска и раздатка недоступны, на сайт ученик не попадает.
  Ссылка сразу на уровень — `&level=2` (кнопки «уровень 1/2/3» на экране выбора уровня; ученикам они не видны).
  Это защита от случайного выхода, а не от взлома: файл материала открытый, адрес без `student=1` покажет раздатку.
- **На телефоне:** верный шаг засчитывается сам, остановка — только на ошибке; кнопка «Проверить» стоит рядом с полем
  (у цифровой клавиатуры iPhone нет «Ввода»); нажатие на уровень сразу начинает тренировку.
- **Настройки:** уровни сложности, типы заданий.
- **Ввод ответа** — по типу задачи, чтобы ошибался ученик в математике, а не в наборе:
  число (с запятой), дробь (два поля этажом), смешанное число (три поля), выбор из вариантов,
  заполнение клеток в выражении («(3x − 2)² = □x² − □x + □»), пошаговый ввод решения.
- **Каждая ошибка объясняется** с вычислением; типичная ошибка называется по имени
  («Ты потерял удвоенное произведение: (a + b)² = a² + 2ab + b²»). После ошибки — новое задание того же типа с другими числами.
- **Подсказки по шагам** со штрафом в очках. Ребёнок идёт к нейросети, когда застрял; подсказка — законный способ сдвинуться.
- **Очки, серия и множитель, рекорд** (`localStorage` в `try/catch`).
- **Итоги** с блоком «Над чем поработать» по типам ошибок.
- **Справка** с теорией по теме — формулировки как в учебнике класса.

В отличие от «Инфошага», **контрольная на 10 минут за компьютером не обязательна**: в классе компьютеров нет,
проверка знаний идёт на бумаге («близнец»). Режим «Домашняя работа» с фамилией и кодом результата — этап 6
плана (`docs/HOMEWORK.md`).
